Halifax County Wills name index

Search everyone named in the Halifax County, North Carolina will abstracts on freeafricanamericans.com: the person making each will, every person given or lent something, and the enslaved people the wills name. Each result shows its will book, page and date, with a link back to the entry in the source.

    How this index was made

    • Every will entry on the source page was read and broken into the will maker, each person given or lent something (with the relationship as the will states it), and each enslaved person named. The citation is the will book volume and page from the abstract; dates show when the will was written and when it was proved in court.
    • When a will names a child or wife by first name only (for example "my son Benjamin"), the index adds the will maker's surname so the person can be found by family name. These are marked "surname added".
    • "Include spelling variants" matches names that sound alike or differ only by doubled letters, so Mathis finds Matthis, Wallace finds Wallis and Wallice, and Bynam finds Bynum.
    • Unclear readings are kept with the source's own question marks, and anything ambiguous is listed under each will's notes. The abstracts were parsed automatically, so check the original entry before relying on a detail. The "View in source" link opens the source page at that will.
    • The source page covers Halifax County, North Carolina, Will Books 1 to 4. The copy available when this index was built ends partway through Will Book 4, page 47.
